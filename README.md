# 🏦 Nama AI

**Nama AI** هو مساعد مالي ذكي يعتمد على الذكاء الاصطناعي التوليدي، تم تطويره ضمن مسار **الذكاء الاصطناعي التوليدي للتقنية المالية**.

---

# 📌 المشكلة

تقدم التطبيقات البنكية الخدمات والمنتجات لجميع العملاء بنفس الطريقة، دون مراعاة اختلاف احتياجاتهم أو سلوكهم المالي، مما يصعّب اختيار المنتج المناسب.

---

# 💡 الحل

يقوم Nama AI بتحليل المؤشرات المالية للعميل داخل البيئة المصرفية، ثم يقدم:

- توصيات مالية مخصصة.
- شرح واضح لأسباب التوصية.
- مساعد مالي ذكي للإجابة عن الاستفسارات.
- انتقال مباشر إلى المنتج أو الخدمة المناسبة.

---

# ⭐ المميزات

- تحليل مالي ذكي.
- توصيات شخصية.
- Explainable AI (تفسير سبب التوصية).
- حماية خصوصية البيانات.
- تجربة مستخدم سهلة وحديثة.

---

# 🔒 الخصوصية

تم تصميم النظام بحيث:

- يتم تحليل البيانات داخل البيئة المصرفية.
- لا تصل البيانات البنكية الحساسة إلى نموذج الذكاء الاصطناعي.
- يعتمد Nama AI على المؤشرات المالية الناتجة عن التحليل فقط.
